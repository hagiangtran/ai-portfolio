# Portfolio AI — Trần Hà Giang

- `index.html`: web portfolio (mở trực tiếp bằng trình duyệt).
- `assets/shots/`: ảnh chụp sản phẩm thật. `capture_panels.py` chụp lại 4 extension Premiere (cần Python + Playwright).
- `cv/cv.html`: bản gốc CV. `cv/2026_AI Course_Tran Ha Giang.pdf`: file nộp vào form.

## Đưa web lên GitHub Pages (để link trong CV hoạt động)
1. Trên GitHub, tạo repo tên **ai-portfolio** trong tài khoản `hagiangtran`.
2. Upload toàn bộ thư mục này (trừ `cv/` nếu không muốn công khai).
3. Settings → Pages → Source: Deploy from a branch → `main` / root.
4. Web chạy tại `https://hagiangtran.github.io/ai-portfolio/`.
